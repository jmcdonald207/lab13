# Draft committee decision

**Pilot the screen for research and defer a live allocation until the committee confirms reserve eligibility and resolves which allocation to use when the estimation window moves VT weight by 30 percentage points.**

The November 17, 2026 run used real adjusted closes from October 2021 through October 2026. The full 60-return window selected 55% SGOV and 45% VT, with 6.83% modeled annual return, 6.74% annual volatility and 55% eligible reserves. The recent 36-return window selected 85% SGOV and 15% VT, with 6.85% return, 1.77% volatility and 85% reserves. Both meet the classroom thresholds of 6.50% return and 3.00% eligible reserves.

Reducing the full-window VT return input from 10.55% (rounded) to 9.55% moved the full-window mix to 50% SGOV and 50% VT, with 6.67% expected return and 7.48% volatility. That run still clears both modeled thresholds. The historical arithmetic means feed the model as estimates and can change with the window. The 15%–50% observed VT weight range summarizes these scenarios and illustrates why the pilot remains a research decision. [Visible results](../output/results.md)
